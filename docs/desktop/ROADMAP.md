# Otter Desktop：实施路线

> 这是实施前的规划快照。当前已实现的功能和实际验证结果，以 [桌面说明](README.md) 与 [验证记录](VERIFICATION.md) 为准。

规划阶段产物，尚未改动远端项目。周期按一名熟悉 Python/TypeScript 的程序员每周约 15–20 小时粗估，受语音供应商与窗口兼容性影响。

## P0：窗口与打包技术验证（2–3 个工作日）
- [ ] 透明小窗口、角色命中、空白穿透、拖动、菜单栏、显示/隐藏、多屏恢复；不抢焦点（D1）。
- [ ] 用简单 Canvas 水獭做反馈，测空闲 CPU/RSS、隐藏停帧（D2）。
- [ ] Electron 启动简单 Python 子进程，stdio 握手、错误展示、退出无孤儿进程；做最小 .app 验证 Finder 启动（D7）。
- [ ] 达到可接受窗口行为和资源指标后冻结 Electron，否则小范围比较 Tauri/AppKit。

## P1：桌面宠物与现有工作助手（约 1 周）
- [ ] 提取 application 报告服务与 notifier 调用，CLI 回归（D8）。
- [ ] 实现 Runtime、受限 IPC、单实例、jobs 状态、线程内 Store 与任务互斥（D3、D7）。
- [ ] 面板显示真实简报和来源；生成任务推送 working/success/error；部分采集失败明确显示（D2、D3）。
- [ ] 设置连接、模型、数据路径；敏感值不回传前端；导入旧配置/数据（D7、D8）。
交付：双击启动的小水獭，点击查看昨日简报，能生成今日简报，任务结束主动提示一次。

## P2：文字陪伴与生活助手（约 1–2 周）
- [ ] ChatProvider 多轮/流式/取消协议；保留批处理 generate 兼容（D4、D8）。
- [ ] conversations/messages 迁移；近期上下文与受限简报检索；显示引用（D4）。
- [ ] 提醒增查改删、持久化调度、恢复与去重；暂停/勿扰策略（D5、D6）。
- [ ] 角色状态机、互动冷却、有限主动问候；可删除偏好（D2、D6）。
交付：可聊“昨天做了什么”，可设置一个真正执行的提醒，普通闲聊不自动上传全部工作资料。

## P3：按键语音（约 1 周）
- [ ] 麦克风权限、录音指示、识别、TTS 播放、播放事件驱动动画（D9）。
- [ ] 停止取消整轮；失败回退文字；拒绝权限不阻塞应用（D4、D9）。
- [ ] 检查原始音频清理、设备切换、延迟和费用。全双工/唤醒词另立里程碑。

## P4：可日常使用的发布包（约 1 周）
- [ ] 打包 Python、插件元数据、模板与 SQL；在无 uv 环境启动验证（D7、D8）。
- [ ] 从旧库升级、失败恢复；整包版本与数据库版本兼容检查。
- [ ] 测睡眠唤醒、重连、多屏、主/子进程崩溃、8 小时驻留；资源目标实测报告。
- [ ] 给他人分发时处理签名/公证与更新来源；首版可先手动替换兼容版本，禁止盲目降级数据库。

## P5：硬件接口与迁移（桌面稳定后）
- [ ] DesktopBody/MockBody 共用协议契约与能力降级测试（D10）。
- [ ] Mac Runtime + ESP32 串口，验证动作 TTL、去重、限幅、失联停止。
- [ ] 单独制定树莓派运行、秘密存储、Mac 工作数据接入方案，再采购机身硬件。

## 关键验证与依赖
P0 → P1 → P2 → P3 → P4 → P5；P1 起持续做最小发布包验证。
已有 pytest/ruff 作为回归基线，报告原有测试实际结果，不引用 README 数量当作执行结果。新增重点测试：取消后迟到 token、重复提醒、迁移失败、SQLite 线程归属、同日期重复生成、后端重启、命中区域和多屏。视觉表现与窗口行为必须在真实 macOS 验收。

## 建议代码落点（均为提案，未创建）
- desktop/：Electron 主进程、preload、宠物/对话/面板、资源。
- src/otter/application/：共享应用服务。
- src/otter/runtime/：生命周期、协议、任务与调度。
- src/otter/companion/：对话、状态、偏好与行为。
- src/otter/devices/：DesktopBody/MockBody，未来硬件。
- src/otter/audio/：后续语音适配器。
- src/otter/migrations/：增量 SQL。
- tests/：Python 回归、协议/迁移测试；desktop/ 内另设窗口集成验证。

第一批实现范围固定为 P0 + P1：让现有 Otter 在桌面上可见、可操作、能呈现真实简报。复杂动画、全双工语音和硬件都不阻塞这批交付。
