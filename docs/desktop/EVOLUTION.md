# Otter 任务进化

## V2 完整进化演出

新增每段2.4秒、40帧的工匠暖金与深潜薄荷演出，包含聚光、像素光环、成长剪影和扫描亮相。设置支持完整 / 0.64秒短版 / 不播放。可跳过演出，不能跳过等待确认；真实任务提前结束可立即切到结果，不因演出延迟操作。回归仍用短版，关闭模式则直接恢复。

## 使用入口

桌面开发版重新启动后，打开「陪伴互动」，下滑到「任务进化」。这里有三形态对比、真实任务状态、独立演示和共同成长记录。

- 陪伴：普通聊天或明确的低 effort 保持原形态。
- 工匠：简报、确认任务及一般明确工作状态。
- 深潜：工匠形态的工作累计超过20秒（等你确认的时间不算）；或上游明确给出 high / xhigh / max / ultra effort、至少四步的任务计划。

可以选择下次任务的外观偏好；它不会切换模型、改变推理参数或增加计算预算。Otter 现在的后台不发送 `effort`，对话式任务的提议也都只有一步，所以自动模式下深潜靠工作时长：工匠形态的工作（生成简报、理解任务、交接处理）累计超过20秒，就原地换成深潜继续，不再播一次进化；等用户确认的时间不计入，普通聊天不参与，任务在20秒内结束则不会潜入。设置里手动选「工匠」时不会潜入深潜。上游将来提供 `effort`、`plannedSteps` 时会直接按它们选择。

## 生命周期

开始 → 按设置播放进化（完整2.4秒 / 简短0.64秒 / 关闭）→ 工作（工匠工作满20秒潜入深潜）→ 等待用户 → 继续执行或验证 → 实际完成 / 失败 → 回到陪伴。

真实任务不等待动画，若任务很快完成，立即进入结果表现。等待用户不会由计时器自动推进。任务取消、切换工作空间和断线会清理旧计时器，迟到结果不能再次庆祝。

## 真实事件

| 来源 | 表现 |
| --- | --- |
| 聊天 streaming / complete / failed / cancelled | 按工作元数据选择形态，回复结束后恢复；聊天不作为已验证成果 |
| 简报 queued / running / finished / failed | 工作、完成或需要帮助；真实生成完成可供记录里程碑 |
| 对话式任务 plan / proposal / confirm | 理解任务、等原面板确认、执行后按实际 ok 反馈 |
| AI 交接 pending | 等待原交接面板决定；请求消失不代表成功，可能被拒绝或过期 |

确认操作中的提议 ID 与调用方 requestId 不同，进化桥按当前真实提议匹配 requestId；缓存的旧确认结果不会完成新的任务。

桌面宠物保留原优先级：拖动、说话、摸头 / 玩耍、睡眠可以覆盖工作形态。第一版这些互动仍使用既有陪伴 GIF，两个工作形态先提供工作、等待、完成三组姿态。

## 演示与成长

演示有独立状态机，只在本地运行，不请求模型、不执行任务、不批准交接、不写成长记录。原来的真实待确认请求不会因「继续演示验证」而执行。

里程碑只接受刚刚收到的真实简报完成或确认操作成功，并要求用户点击「记下这次完成」。重复点击去重，最多保留20条，随 `desktop.json` 中的 evolution 设置在本机持久化。普通聊天、演示、取消或失败不计入，也不按 token 或在线时长累积。

第一版尚未做等级数值、饰物解锁或更长的进化树；三种形态不限制任何任务功能。

### 实体水獭

固件 0.9.0 起，板子有第二个动画库（数据分区 3 MiB 处，`hardware/scripts/build-evolution-pack.py`），没有接在旧的 2 MiB 动画槽后面。进化帧复制在 `hardware/assets/evolution/`。`BodyBridge` 收到 `evolution.changed`，在板子原本显示平常、工作、思考、专注时，改发同一形态和阶段的片段（`to_<形态>`、`<形态>_work` 等）；朗读、互动、提醒、睡觉、离线仍优先。固件的 `FACE LIST` 里没有这些片段时，照旧发原来的表情。进化片段借用原来的语音：工作“整理中。”、等你确认“你来定。”、完成“办好啦！”。详见 `hardware/docs/LESSON-11-EVOLUTION.md`。

## 当前不足

- 深潜目前按工作时长判断，还不能识别任务本身的难度；上游提供 `effort` 或至少四步的 `plannedSteps` 后，会优先按它们选择。
- 完整演出采用六个关键姿态与光效时间轴，简短演出保留四关键帧；首尾仍有少量比例变化，尚未制作360度身体旋转。失败姿态复用等待卡片并显示明确说明。
- 长期成长先记录成果，没有自动解锁外观。
- 已安装的 App 不会自动被本次源码修改替换。
