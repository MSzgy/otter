## 2026-09-25 浏览器实机复现

在 Chrome 扩展控制的浏览器中已打开自有 localhost 测试页，并确认可见固定正文；Otter 列出两个 Chrome 实例，但点击刷新返回无窗口。代码证据：AwarenessPane 的两个实例按钮都只发送相同 bundleId，Awareness.captureBrowser 与 JXA Application 也只按 bundleId 定位，没有传递 PID。该缺陷不能继续归类为用户未授权。0.7.3 已贯穿列表、自动感知和指定标签正文读取传递 PID，原生通过 ScriptingBridge 精确寻址；旧的 bundle-only 请求在多实例时拒绝执行。2026-09-26 实测分别返回 0 窗口与 2 窗口，并在第二个实例找到自有测试页；初次正文错误由新适配器动态调用方式引起并误报权限，已修复；原生读取自有正文及隐藏/表单过滤已通过，0.7.3 安装版 UI 已列出正确实例的 22 个标签，指定测试页正文进入预览并排除隐藏/表单内容。测试标签已关闭。

0.7.3 已安装到 ~/Applications/Otter.app。Chrome 列表和正文 UI 验收通过；ad-hoc 更新后的辅助功能权限待刷新，0.7.2 已验证的选区和应用文字需在新版恢复授权后复验。真人麦克风和独立聊天快捷键仍未完成验收。

### 记忆与个性（0.8.0）范围

- 只保存用户在输入框里明确写出的“记住：……”或在记忆页手动添加的内容；附件、网页、窗口文字、OCR 和模型回复都不会写入。
- 聊天引用相关记忆，并在消息下方列出；可以从聊天跳转修改，也可以说“忘掉刚才那条”撤回。
- 支持“这件事不要记住”、关闭本轮记忆、全局关闭记忆，以及清空全部记忆。
- 称呼与说话风格独立于记忆开关生效。
- 真实云端模型对记忆的实际引用效果未做人工评估；检索为本机关键词匹配，措辞差异大时可能漏选。
