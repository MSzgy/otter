## 2026-09-25 浏览器实机复现

在 Chrome 扩展控制的浏览器中已打开自有 localhost 测试页，并确认可见固定正文；Otter 列出两个 Chrome 实例，但点击刷新返回无窗口。代码证据：AwarenessPane 的两个实例按钮都只发送相同 bundleId，Awareness.captureBrowser 与 JXA Application 也只按 bundleId 定位，没有传递 PID。该缺陷不能继续归类为用户未授权。下一步需贯穿列表、自动感知、指定标签正文读取传递实例身份，并验证失效进程不会回退到另一实例；真实多实例与正文验收仍未通过。测试标签已关闭。
