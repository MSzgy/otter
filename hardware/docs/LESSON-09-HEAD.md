# 第九课：两轴头部——纸板原型、标定和预设动作

水獭的头装在两个舵机上：**1 号管左右**（装在底座里），**2 号管上下**（点头）。整块 ESP32 板就是脸。这一课先用纸板搭出能转的头，再量出它实际能转多大，最后让板子自己做点头、摇头、左右看这些动作。固件版本 `otter-face-0.7.0`。

左右都以**你坐在屏幕前看它**为准：“向左看”就是头转向你的左手边。

## 1. 先把舵机转到中位，再装舵盘

SC09 的位置是 0～1023，对应大约 300°，中位是 511。舵盘在中位时装成“正对前方、屏幕竖直”，两边留的行程才差不多。

    cd /Users/zouguoyang/Developer/otter/hardware
    .tools/python/bin/python scripts/face-control.py center 1
    .tools/python/bin/python scripts/face-control.py center 2

转到中位以后，**不要再用手拧输出轴**。装舵盘时，选一个最接近“正前方”的齿位插上就行，差一点没关系，标定会量出真正的正前方。

## 2. 纸板头部怎么搭

材料：快递箱的瓦楞纸板、热熔胶或双面胶、扎带、舵机自带的舵盘和小螺丝、一根竹签或 M2 螺丝、美工刀和尺子。

        ┌──────────────┐
        │  ESP32 屏幕   │  ← 头：纸板托住整块板子
        └──────┬───────┘
     ┌─────────┼─────────┐  ← U 形支架
     │ 2号舵机 ●── 轴 ──● 竹签（另一边的轴）
     └─────────┬─────────┘
           ┌───┴───┐        ← 转盘，用螺丝固定在 1 号舵机的舵盘上
           │ 1号舵机 │        输出轴朝上
     ┌─────┴───────┴─────┐
     │     底座盒子        │  ← 舵机控制板放在这里，里面压点重物
     └───────────────────┘

- **底座要重、要稳**。1 号舵机转的时候，底座不能跟着转。盒子里压几枚硬币就行。
- **1 号舵机**竖着嵌进底座顶面，输出轴朝上。用扎带或热熔胶固定舵机外壳，别让胶碰到输出轴。
- **转盘**是一块 6～8 cm 的纸板，用舵盘自带的小螺丝固定在舵盘上，U 形支架粘在转盘上。
- **U 形支架**有两条竖臂：一边装 2 号舵机，输出轴横着朝里；另一边用竹签或螺丝做一根和它对齐的“假轴”。头被两边一起托住，纸板才不会歪。
- **头**是一个纸板托，ESP32 板放进去，别挡住屏幕、USB 口和触摸。托的两侧分别连到 2 号舵机的舵盘和假轴上。喇叭也粘在头上，线短。
- **上下转的轴要穿过头的重心**，这一点最重要。如果轴在头的最下沿，头总想往前栽，2 号舵机就得一直用力。轴大概穿过板子的中间，前后差不多一样重就对了。
- **走线**：头上有三组线要往下走：ESP32 的 USB-C 线（接 Mac）、到控制板的 4 根线（GPIO43、GPIO44、GND、3V3），以及 2 号舵机的 3 芯线。在头后面留一个松一点的线圈，再用胶带把线固定在转盘上，让线跟着头一起转，不要被硬拖着。
- 左右先别追求太大，±60° 就够用了，线也安全。
- 别用手硬拧装好的头，会伤到齿轮，纸板也会变形。要调整就用下面的标定工具让舵机自己转。

嫌纸板软，也可以买现成的“SG90 二轴云台支架”（选不带舵机的）。它按 SG90 做，SC09 稍大一点：微雪官网写 SC09 是 23.2 × 12.0 × 25.5 mm，SG90 机身约 22.2 × 11.8 mm，卡槽可能要用刀或锉修宽一点。支架靠舵盘连接舵机，SC09 自带的舵盘可能要修剪或加胶。底下那个装 1 号、上面那个装 2 号；顶上的小平台比 ESP32 板小，先粘一块纸板再贴板子；它的点头轴在平台下面，不穿过头的中间，板子很轻，SC09（2.3 kg·cm@6V）托得住。底座要固定在有分量的东西上。

## 3. 标定：量出真实可转范围

装好后运行（桌面 App 要先关掉，或者先在设置里关闭“实体水獭”，否则串口被占用）：

    .tools/python/bin/python scripts/head-calibrate.py

| 按键 | 作用 |
|---|---|
| ← / → | 1 号舵机（左右）位置减 / 加 |
| ↑ / ↓ | 2 号舵机（上下）位置加 / 减 |
| 空格 | 步长 5 步 ↔ 20 步（约 1.5° ↔ 6°） |
| c | 标记正前方（两个舵机一起记） |
| l / r | 标记最左 / 最右 |
| u / d | 标记最上（抬头）/ 最下（低头） |
| x | 放松两个舵机 |
| s 或回车 | 保存到板子 |
| q | 不保存退出 |

步骤：

1. 用方向键把头转到正对前方、屏幕竖直，按 `c`。
2. 往一边一点点转，直到快碰到东西或者线开始拉紧，往回退一步。看头实际朝向哪边：朝你的左手边就按 `l`，右手边就按 `r`。方向键和左右的对应关系取决于舵机怎么装，不用管。
3. 另一边同样做一次。上下也一样：抬头到头按 `u`，低头到头按 `d`。
4. 按 `s` 保存。板子会记住（断电也不丢），然后自动回到正前方。

标定时板子放宽了范围，但仍然有保护：每次最多转 30 步、每秒 40 步，卡住会自动放松（工具会提示“这里就是极限附近”）。停 20 秒不动，舵机也会放松；2 号放松后头可能往下沉一点，再按一下方向键就会重新上力。

工具和固件都会检查：左右两头必须分在正前方两边，每边至少 20 步（约 6°），上下也一样。

## 4. 预设动作

| 动作 | 做什么 | 速度 |
|---|---|---|
| `center` | 回到正前方 | 80 步/秒 |
| `nod` | 点头两下：低头到下方行程的 45%，再稍微抬一点 | 200 步/秒 |
| `shake` | 摇头：左右各转到行程的 35%，来回一次半 | 200 步/秒 |
| `look_left` / `look_right` | 转到左 / 右行程的 80%，停 1.2 秒，回正 | 120 步/秒 |
| `look_up` | 抬头到上方行程的 70%，停 1.2 秒，回正 | 120 步/秒 |

动作都用“行程的百分之几”来定义，所以换一个头、舵机反着装，都不用改代码，重新标定就行。每个动作最后都回到正前方，头不会停在转开的位置。

    .tools/python/bin/python scripts/face-control.py motion nod
    .tools/python/bin/python scripts/face-control.py motion look_left
    .tools/python/bin/python scripts/face-control.py head

## 5. 指令

| 发送 | 回复 |
|---|---|
| `MOTION nod` | `OK MOTION nod`，做完再报 `EVENT motion nod done` |
| `MOTION STOP` | `OK MOTION STOP`，停在当前位置并保持 |
| `MOTION LIST` | `{"motions":["center","nod",...]}` |
| `HEAD` | `{"head":"calibrated","pan":{...},"tilt":{...}}` |
| `HEAD CALIBRATE` / `HEAD CANCEL` | 进入 / 退出标定模式 |
| `HEAD SAVE 左 中 右 上 中 下` | 保存六个位置 |
| `HEAD FORGET` | 清掉标定，头拆了重装时用 |
| `INFO` | 新增 `"head":"calibrated"` |

- 每个开始了的动作最后都有一行结果：`done` 做完、`failed` 舵机出了问题（已经放松，见前面那行 `EVENT servo ... fault`）、`stopped` 被新动作、`MOTION STOP` 或任何 `SERVO` 指令打断。
- 新动作替换正在做的动作，不排队。
- 没标定时 `MOTION` 回 `ERR head not calibrated`；标定中回 `ERR head calibrating`。
- `SERVO MOVE` 仍然是调试用。范围：没标定时还是第六课的 361～661；标定后只能在量出来的范围里；标定中可以到舵机自己的限位，但每次最多 30 步。

## 实测（2026-10-25）

- 固件 0.7.0 烧录后：`INFO` 报 `"head":"uncalibrated"`，`MOTION LIST` 列出 6 个动作，没标定时 `MOTION nod` 被拒绝。
- 两个舵机用 `center` 回到中位（1 号 511，2 号 515），准备装舵盘。
- **还没在舵机上测过**：标定模式、`HEAD SAVE`、6 个预设动作的速度和幅度、动作中的故障处理、`head-calibrate.py` 的按键操作。头部装好后补测，速度、到位容差和负载阈值可能要按实际的头调整。
