# 第十课：用板子看看附近的 Wi-Fi

ESP32-S3 自带 Wi-Fi（只支持 2.4 GHz）和低功耗蓝牙，天线在板子上。这一课第一次打开无线电，但**只看不连**：列出附近网络的名字、信号强度、信道和是否加密，不加入任何网络、不需要也不保存密码。固件版本 `otter-face-0.8.0`。

## 怎么读

- **dBm** 是信号强度，负数，越接近 0 越强。-50 很强，-70 能用，-85 以下就很勉强了。条形图按 -60 / -70 / -80 分档。
- **信道**：2.4 GHz 在国内有 1～13 号信道。附近很多网络挤在 1、6、11 附近是常事；信道挤，网速会受影响。
- **加密 / 开放**：开放网络谁都能连，也谁都能看到里面传的东西。
- **隐藏网络**不广播名字，显示为“（隐藏网络）”。
- 同一个路由器的 5 GHz 网络这里看不到，因为芯片只支持 2.4 GHz。

## 板子怎么做

- `WIFI SCAN` 立即回 `OK WIFI SCAN`，扫描在后台进行，约 3～4 秒后输出一行 `{"wifi":[...],"found":28}`。扫描期间动画、触摸、舵机安全检查照常运行，`PING` 也立即回应。
- 扫描时再发 `WIFI SCAN` 回 `ERR wifi busy`。
- 扫描结束后**无线电马上关掉**。`WiFi.persistent(false)` 保证不往 Flash 写任何 Wi-Fi 设置。
- 网络名可能包含任意字符：引号、反斜杠、控制字符会转义成合法 JSON，中文名照常显示。
- 加入 Wi-Fi 库后固件从 0.4 MB 变成 0.96 MB，占应用分区的 30%。

## 实测（2026-10-25）

- 找到 28 个网络，最强 -51～-59 dBm，全部加密，有中文网络名，显示正常。
- 扫描约 3.7 秒；连发两次时第二次回 `busy`；扫描中 `PING` 立即回应；第一次扫完马上再扫，也正常。

## 下一步：连上 Wi-Fi 要想清楚的事

只扫描是安全的。如果要**加入**网络：

- 密码要存在板子里。只能由你自己在终端里输入，存在板子的 Flash 中，不能写进代码或公开仓库。
- 板子只**主动连出去**（比如联网对时），不开任何端口接收指令，局域网里的其他设备就控制不了它。
- 如果以后要让 Mac 通过 Wi-Fi 控制它，得先做配对和口令，否则同一个网络里谁都能让它转头、说话。
