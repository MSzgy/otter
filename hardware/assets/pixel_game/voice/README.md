## 长度与格式

- 21 条，单条 0.48～1.40 秒，总时长约 18.6 秒。
- 原音保留在 `source/`。只去前后低电平空白、统一采样与音量，并加极短淡入淡出，不截断台词。
- `wav/`：16kHz、单声道、16-bit PCM WAV。
- `pcm/`：同一份音频的有符号 16-bit 小端原始采样，无文件头，共 594,758 字节（约 581 KiB）。
- 比一轮 GIF 长的声音，配两轮动画。声音只播一次，不能随 GIF 重复。

## 播放规则

- 网页默认不自动发声。可以手动试听，或主动开启“切换表情时播放一次”。
- 陪伴、专注和通用说话素材默认只供手动试听，避免打扰或盖住真正的聊天语音。
- 倾听提示在麦克风启动前播放，正在录音时保持安静。
- 同时只用一个播放器。新状态停止旧声音；自动播放有冷却，切换静态 / 动画不重播。
- 待确认、保存中、完成严格对应不同状态，语音不能代替确认按钮或成功回执。
